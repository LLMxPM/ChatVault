# 任务中枢信息架构重构

## 决策定稿

1. **立即运行与定时共用一条流水线**：与 `scheduled-run` 同构——扫描 → 归档 → 发布日志 → 拉取日志。
2. **发布/拉取不提供手动入口**：失败进入任务状态；恢复保留为低频独立操作。
3. **WebDAV 属于基础设置**：配置、测试、凭据；任务只消费连接。
4. **采集范围与调度属于任务配置**。

## 导航

| 导航 | id | 职责 |
| --- | --- | --- |
| 文件库 | `library` | 检索、筛选、来源标注（改名/收藏） |
| 任务 | `tasks` | 采集范围、调度、运行流水线、队列、恢复 |
| 设置 | `settings` | 身份、WebDAV、缓存、外观、存储、关于 |

取消独立「采集」「归档」导航。来源标注移出任务，服务文件库。

## 任务页信息层级

```
任务
├── 页头状态条
│   调度：开/关 · 周期 · 计划任务已/未注册 · 上次运行
│   连接：WebDAV 未配置 | 已连接
│   [立即运行] 主按钮 · 跑流水线
│
├── 采集范围
│   ├── 采集源（持久 collectSources；按适配器类型标记）
│   │   ├── 微信 4.x 根目录（可展开账号，手动可勾选本次）
│   │   └── 附件目录（仅系统目录选择）
│   注：实际扫描范围只来自该列表；立即运行仅临时选择微信账号
│
├── 调度
│   启用定时 · 周期（分钟）· 状态徽章
│
├── 运行与队列
│   本轮流水线阶段：扫描中 → 归档中 → 同步中 → 完成/失败
│   上传队列表：待上传/失败/暂停/已校验 · 重试/暂停
│
└── 恢复（折叠区）
    从远端恢复索引 · 二次确认
```

## 设置页收缩

保留：身份与资料库、WebDAV 连接（含测试/密码/清除）、缓存、外观、存储概览、关于。

移出：采集源、启用定时扫描、扫描周期。

## 流水线契约

### 立即运行

- 与 CLI `scheduled-run` 同构，复用同一套 scan/archive/sync 核心。
- 微信范围：手动可勾选；未勾选任何账号且没有可用附件目录 → 禁用按钮。
- 未配置 WebDAV：只完成本地扫描，队列停在「待归档」，状态条提示去设置。
- 进行中：页头阶段指示；按钮变「停止/禁用」；结束后 toast + 刷新队列。

### 定时

- 开关写入 `schedule_enabled` / `scan_interval_minutes`，注册/注销系统任务。
- 定时始终扫描 `collect_sources` 中全部已配置采集源；微信源下扫描全部已识别账号。
- 自动完成归档与日志同步；失败记录在任务/日志，不弹手动同步按钮。

### 队列

- 保留现有状态与重试/暂停。
- 「重试」只改状态；真正上传由下次流水线或定时完成。若希望重试即跑，需单独确认（默认不跑）。

### 发布/拉取

- UI 不再出现。
- 失败可在运行摘要中展示（阶段=同步失败 + 错误信息），支持再次「立即运行」。

## 跨页流

```
首次空库 → 任务（采集范围）→ 立即运行 → 文件库
未配置 WebDAV → 任务状态条/空态 → 设置（WebDAV）
文件库来源改名 → 就地或侧栏，不跳任务
设置改 WebDAV → 任务连接状态刷新
```

| 设置 · WebDAV/缓存/外观… | 设置（保留） |

## 实现注意

1. 后端建议增加统一入口 `run_pipeline`（或扩展 scheduled-run 供桌面调用），避免前端拼四条命令且与 CLI 再次漂移。
2. `run_scan` 应后端读取带适配器类型的 `collect_sources`，取消前端 merge 双源和临时目录参数。
3. 删除前端死接口 `saveWebdavConfig` 的无用导出（或保留给计划任务/CLI 复用但 UI 不用）。
4. 设置 mega-save 拆块：WebDAV、缓存、身份各自保存，避免改主题触发计划任务重注册。
5. 导航与 first-run 引导同步改文案。
