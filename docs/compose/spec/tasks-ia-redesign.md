# 任务中枢信息架构重构

> 补充（运行日志）：任务页已增加「运行历史」卡片；流水线写入 `task_runs` / `task_run_stages` / `task_run_items`，运行中通过 Tauri 事件展示阶段与文件进度。详见《架构与同步设计》§5.1。

## 决策定稿

1. **立即运行与定时共用一条流水线**：与 `scheduled-run` 同构——扫描 → 归档 → 发布日志 → 拉取日志。
2. **发布/拉取不提供手动入口**：失败进入任务状态；恢复保留为低频独立操作。
3. **WebDAV 属于基础设置**：配置、测试、凭据；任务只消费连接。
4. **采集范围与调度属于任务配置**。

## 任务页信息层级

```
任务
├── 页头状态条
│   调度：开/关 · 周期 · 计划任务已/未注册 · 上次运行
│   连接：WebDAV 未配置 | 已连接
│   [立即运行] 主按钮 · 跑流水线
│
├── 采集范围
│   ├── 采集源（持久 collectSources；按适配器类型标记）
│   │   ├── 微信 4.x 根目录（可展开账号，手动可勾选本次）
│   │   └── 附件目录（仅系统目录选择）
│   注：实际扫描范围只来自该列表；立即运行仅临时选择微信账号
│   注：进页首屏用 collect_source_cache 秒开；后台仅 checkDirectory。
│        完整账号识别仅在添加/重新识别/无缓存时触发；
│        账号勾选持久化于 collect_selected_accounts（null=默认全选）
│
├── 调度与运行
│   启用定时 · 周期 · 强制全量；主按钮在页头
│
├── 运行历史 / 上传队列（Tab）
│   运行：扫描 → 上传 → 同步 → 完成/失败
│   队列：待处理（默认）/待上传/失败/缺失/暂停/已校验 · 重试/暂停
│
└── 恢复（折叠区）
    从远端恢复索引 · 二次确认
```

## 设置页收缩

保留：身份与资料库、WebDAV 连接（含测试/密码/清除）、缓存、外观、存储概览、关于。

移出：采集源、启用定时扫描、扫描周期。

## 流水线契约

### 立即运行

- 与 CLI `scheduled-run` 同构，复用同一套 scan/archive/sync 核心。
- 微信范围：手动可勾选；未勾选任何账号且没有可用附件目录 → 禁用按钮。
- 未配置 WebDAV：只完成本地扫描，上传队列项停在「待上传」，状态条提示去设置。
- 进行中：页头阶段指示；按钮变「结束运行」；结束后 toast + 刷新队列。
- 结束运行：协作式取消（`cancel_requested`），CLI 定时运行同样可被桌面取消；不 kill 进程。详见《架构与同步设计》§5.1.7。

### 定时

- 开关写入 `schedule_enabled` / `scan_interval_minutes`，注册/注销系统任务。
- 定时始终扫描 `collect_sources` 中全部已配置采集源；微信源下扫描全部已识别账号。
- 自动完成归档与日志同步；失败记录在运行历史/日志，不弹手动同步按钮。
- CLI 运行写入同一 `task_runs`；桌面任务页通过 DB 轮询展示进行中的定时运行。

### 上传队列

- UI 称「上传队列」（`upload_tasks` / 归档单元）；默认筛选「待处理」。
- 保留现有状态与重新入队/暂停；失败行展示错误原因与重试次数。
- 「重新入队」只改状态；真正上传由下次运行完成。
- 「本地缺失」项支持确认后删除，只删除队列项，保留文件库与运行历史，清除历史明细的重试关联；后端拒绝删除其他状态。

### 发布/拉取

- UI 不再出现。
- 失败可在运行摘要中展示（阶段=同步失败 + 错误信息），支持再次「立即运行」。

## 跨页流

```
首次空库 → 任务（采集范围）→ 立即运行 → 文件库
未配置 WebDAV → 任务状态条/空态 → 设置（WebDAV）
文件库来源改名 → 就地或侧栏，不跳任务
设置改 WebDAV → 任务连接状态刷新
```

## 实现约束

1. 后端统一入口 `run_pipeline`（或扩展 scheduled-run 供桌面调用），避免前端拼四条命令且与 CLI 漂移。
2. `run_scan` 由后端读取带适配器类型的 `collect_sources`，前端不维护双源与临时目录参数。
3. 设置分块保存：WebDAV、缓存、身份各自保存，避免改主题触发计划任务重注册。
