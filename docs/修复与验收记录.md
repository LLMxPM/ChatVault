# 可靠性修复与验收记录

日期：2026-09-11。本次修复覆盖代码审查发现的 12 项问题，不代表 V1 全部功能已经交付。

## 已修复

| 问题 | 当前行为 |
| --- | --- |
| 多设备默认身份冲突 | 首次生成并持久化 UUID；CLI 和桌面使用同一身份。旧固定身份迁移后重新发布事件，来源记录 ID 保持不变 |
| 失败事件被游标跳过 | 数据、事件历史、幂等标记和游标在同一事务中提交，任一步失败整片回滚 |
| 未完成对象被日志引用 | 只发布对象已归档的连续事件；发布和拉取均验证远端对象完整哈希及大小 |
| 已有损坏对象被标为已校验 | 复用前完整回读；MOVE 禁止覆盖，竞争发生后同样需要完整验证 |
| 源文件变化导致历史版本丢失 | 入库前复制到数据库旁的 `.objects` 目录并验证稳定内容，各版本保留独立位置记录 |
| 设备注册失败无法续作 | 没有新事件也重试注册；待发布分片持久化，提交响应丢失后复用原分片 |
| 定时归档不重试 | CLI 与桌面共用归档队列；可重试失败采用 30 秒起步、最多 1 小时的退避，手动重试立即入队 |
| 切换 Vault 复用旧状态 | 连接验证成功后绑定索引与远端根地址、Vault ID；后续拒绝切换，其他资料库需独立数据库 |
| WebDAV 命名空间不兼容 | 使用 XML 命名空间解析，支持任意 DAV 前缀与实体转义，网络错误不再当作空目录 |
| 手动与定时配置不一致 | 同步页读取和保存 SQLite 连接配置，设置页与计划任务共用；密码存储于系统凭据库 |
| 分类搜索漏查 | 分类过滤在数据库分页前执行；桌面每页 100 条，支持翻页，账号选项不再取自当前页 |
| 软删除后仍能检索 | 持久化 tombstone，所有查询统一隐藏删除记录；删除先于新增到达时仍保持删除状态 |

另外补充了分片身份、事件数量、序列、路径、版本和长度校验，按 epoch 保存独立游标并恢复全部历史 epoch。批量发布会处理超过 500 条的事件。微信月份目录不再被写成会话标识。

远端使用 HTTPS，HTTP 仅允许回环地址的本机测试；禁止自动重定向和相对路径穿越。已有 Vault 必须通过格式版本和算法检查。连接测试验证创建目录、上传、HEAD、PROPFIND、MOVE 和完整回读，并清理本次随机测试目录。

## 升级行为与限制

- 数据库自动迁移到结构版本 2，保留来源、任务、设置和已有游标。
- 旧库没有远端绑定信息时，首次连接先验证已归档对象和游标对应的远端提交，避免把历史状态误绑定到新建空 Vault。
- 旧任务没有受控副本时，只有原文件内容仍与记录哈希一致才能补建副本；不一致或缺失会报告错误，不会上传错误版本。
- 旧实现已覆盖的远端提交、已被覆盖且没有备份的本地版本，不能通过代码升级凭空恢复。
- 未就绪对象会阻止后续连续事件发布，须先处理相应任务；不会跳过缺口。
- 受控副本目前保留在本机，尚未实现容量上限和自动清理。
- 文件下载、预览、系统打开、快照导入、显式撤销删除、完整字段冲突合并、托盘和安装包仍属于后续开发范围。

## 验证方法

前端：`pnpm --filter chatvault-desktop build`，执行 Vue 类型检查和生产构建。

Rust：`./scripts/build_windows.ps1 test`。脚本将实际 Cargo 失败码返回给调用方。

回归用例位置：

- `crates/index/tests/reliability.rs`：旧库迁移、版本副本、源文件删除、失败退避、身份迁移、Vault 绑定、分页及软删除。
- `crates/sync/tests/recovery.rs`：回环 WebDAV 模拟服务，覆盖事务中断、提交响应丢失、注册失败、对象缺失和损坏、分片声明错误、跨 epoch 恢复及多分片发布。
- `crates/webdav/src/propfind.rs`：DAV 命名空间前缀和 XML 实体解析。

这些测试不连接用户的真实 WebDAV，也不修改用户资料库。真实 NAS 兼容性、双机安装、网络性能与系统计划任务触发仍需实机验收。
